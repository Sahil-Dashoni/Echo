# Echo – Real-Time Chat Application

Echo is a MERN stack–based real-time chat application that enables users to communicate instantly using WebSockets. It provides secure authentication, online user status, and profile management with a responsive user interface.

---

## Features

* Real-time one-to-one messaging using Socket.io
* Secure authentication with JWT and password hashing
* Live online/offline user status
* User profile and avatar management
* Responsive UI for desktop and mobile
* Global state management using Redux Toolkit

---

## Tech Stack

* React.js, Redux Toolkit
* Node.js, Express.js
* MongoDB
* Socket.io
* JWT, bcrypt.js

---

## Setup

```bash
git clone https://github.com/your-username/echo-chat-app.git
cd echo-chat-app
```

```bash
cd server && npm install
cd ../client && npm install
```

```bash
cd server && npm start
cd client && npm start
```
